# GEMM（SGEMM）

单精度矩阵乘：`C(M×N) = A(M×K) × B(K×N)`，全部行主序。

## 状态

| 阶段 | 版本 | 实现要点 | 状态 |
| --- | --- | --- | --- |
| CUDA | v0 | 朴素实现（每线程一个输出元素，全局内存直访） | 未开始 |
| CUDA | v1 | 共享内存分块（tile + block 归约），每线程一个输出 | 未开始 |
| CUDA | v2 | v1 + 向量化访存 / 每线程多元素微调 | 未开始 |
| Triton | t0 | 与 CUDA 同规格的 Triton 实现 | 规划中 |
| Triton | t1 | 与 CUDA 性能对照并记录 | 规划中 |

- 正确性判据：相对误差 ≤ 1e-3（累加顺序/粒度不同所致，见 `docs/benchmark-methodology.md`）。
- 指标：`TFLOPS = 2·M·N·K / 中位耗时`。

## 版本规划说明

- **v0 朴素**：建立正确性基线，速度不设预期。
- **v1 共享内存分块**：经典 tile 方案，掌握分块维度选择与 bank conflict 的规避。
- **v2 向量化 / 每线程多元素**：在 v1 基础上做 `float4` 装载与计算粒度微调，追求寄存器级复用。
- 后续（可选）：考虑仿射对齐 `A^T` 版本、split-K 或更细粒度优化，视学习节奏再定。

## 参考规模

- 默认：`M=N=K=2048`（fp32），便于与朴素版对比且单轮耗时可控。
- 可选更大：`M=N=K=4096`。
- tile 默认 32，block 256（v1 起）。
