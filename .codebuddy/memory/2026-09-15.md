## 讨论：GEMM v2 共享内存 / tile 与 blockDim

- 实测本机（RTX 4060 Laptop, sm_89）共享内存：每 block 48 KiB 静态上限、opt-in 99 KiB、每 SM 100 KiB（详见 MEMORY.md）。
- 澄清 `sgemm_v2` 共享内存 = `2·TILE_SIZE²·4` B（TILE_SIZE=32 → 8 KiB，动态 0）；occupancy 瓶颈是线程数（1024 线程/block vs Ada 1536/SM），不是共享内存。

## 重构：GEMM 模板参数 BLOCKSIZE → TILE_SIZE

- 文件：`include/sgemm_v1.cuh`、`include/sgemm_v2.cuh`、`src/sgemm_v1.cu`、`src/sgemm_v2.cu`、`src/main.cu`、`README.md`（3 处）；`main.cu` 常量改为 `kSgemmV1TileSize` / `kSgemmV2TileSize`。
- 理由：`BLOCKSIZE` 易被理解为 block 线程数，实际它是输出 tile 边长（线程数 = TILE_SIZE²）。
- 验证：`cmake --build build --target gemm` 通过，`./build/operators/gemm/gemm` 4/4 PASS（v2 0.3034 ms / 0.885 TFLOPS）。
