## 1. 环境与口径

设备          : NVIDIA GeForce RTX 4090 (sm_89), 128 SM, 23.5 GB
驱动 / CUDA   : 580.105.08 / CUDA 12.8.93
理论峰值带宽  : 1008.1 GB/s   (2 × 10.501 GHz × 384 bit / 8，估算值)
构建          : Release, block=256, CMAKE_CUDA_ARCHITECTURES=89
严格档采样    : 500 次预热 + 21 组 × 5000 次
                (tier=5，由 tier=clamp(round(SM/24),1,10) 得出；基准机 24 SM 为 100/21×1000)
主指标        : 中位数；P5/P95 为波动区间
有效带宽口径  : Reduce  = (读 n 个 float + 写 grid 个部分和) / 中位耗时
                Softmax = (读 1 次 + 写 1 次) × rows × cols × 4 B / 中位耗时
回归结果      : Reduce 8 内核 × 10 场景 = 80/80 PASS (容差 1e-3)
                Softmax 12 内核 × 20 场景 = 240/240 PASS (容差 1e-5)

## 4. 观察

1. **Reduce 全面 0 spill / 0 栈帧，寄存器 10–22**：v7 以 16 寄存器、128 B 静态 smem
   达成最高有效带宽 1424.50 GB/s，相对 v0 提升约 4.1×，与算子 README 记录的瓶颈迁移
   主线（分歧 → 归约同步 → 全局访存）一致。
2. **Reduce 的带宽数字不可当显存带宽看**：n=2^20 工作集仅 4 MiB，远小于 4090 的 72 MB
   L2，预热后输入驻留片上，1424 GB/s 反映的是 **L2 命中带宽**（> 理论显存峰值
   1008.1 GB/s 即为佐证）。结论仅用于同规模横向对比，与算子 README 的带宽可比性警示
   一致。
3. **Softmax 的 64 MiB 输入 + 64 MiB 输出 = 128 MiB 已超过 72 MB L2**，因此
   4096×4096 上 ~918 GB/s 更接近**显存带宽**，已达理论峰值 1008 GB/s 的约 91%——
   该形状下 v1…v5 与 online-v1/v2/v4 已全部贴着带宽上限，版本间差异落在
   0.146–0.150 ms 的窄带内，进一步优化的空间主要在 v0/online-v0（每线程一行、
   访存不合并）而非这些版本。
4. **online_softmax_v3 的 63 寄存器与 online_softmax_v3_false 的 64 B 栈帧**在
   RTX 4090 上得到与 RTX 4060 Laptop 一致的相对关系（v3 宽行 875.83 GB/s 略低于
   v3_false 的 901.89 GB/s），说明该结论与设备无关，源于寄存器/占用权衡本身。

## 5. 附录：ncu 硬件计数器不可用（原因与复跑方式）

现象：`ncu` 报 `ERR_NVGPUCTRPERM`，连 `--section LaunchStats` 这类不依赖计数器的
section 也在权限检查阶段被拦截，不产出任何报告。

原因：驱动侧 `/proc/driver/nvidia/params` 中 `RmProfilingAdminOnly: 1`，而容器内进程
缺少 `CAP_SYS_ADMIN`（`CapEff = 0xa80425fb`，bit 21 = 0）；`/sys/module/nvidia/parameters/`
下不存在对应可写项，容器内无法解除。

待宿主侧开启计数器权限（`NVreg_RestrictProfilingToAdminOnly=0` 或给容器
`CAP_SYS_ADMIN`）后，可按内核逐个复跑（每次只剖该内核的首次启动，产出 `.ncu-rep`
可用 `ncu-ui` 打开）：

    ncu -k 'regex:^<内核名>$' -c 1 --set detailed \
        -o benchmark/profile-rtx4090/ncu/<内核名> --force-overwrite \
        --log-file benchmark/profile-rtx4090/ncu/<内核名>.txt \
        ./build/operators/<算子名>/<算子名>
